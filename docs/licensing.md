# License and data provenance

Original source, original NumPy/SciPy BPR implementation and generated sample data are MIT.
No external recommendation code, public dataset, pretrained factors, or model artifacts
are bundled. The synthetic generator uses no external assets or personally identifying data.

Third-party dependencies retain upstream licenses. LightGBM is MIT; NumPy, SciPy,
pandas and scikit-learn use BSD-style licenses; Optuna and FastAPI use MIT. Check
installed distribution notices before redistribution. Project MIT does not replace them.

Primary sources:
- https://github.com/microsoft/LightGBM/blob/master/LICENSE
- https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRanker.html
- https://lightgbm.readthedocs.io/en/stable/Parameters.html

- https://github.com/scipy/scipy/blob/main/LICENSE.txt

No MovieLens adapter is included: its dataset terms are separate from software licensing,
and it is unnecessary for a self-contained e-commerce demonstration. For real data,
review source permission, privacy, retention, catalog timestamps and exposure semantics.
